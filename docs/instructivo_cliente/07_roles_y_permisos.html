Tropa Gym — Roles y permisos

Quién puede hacer qué

Tres accesos, pensados para que cada uno vea solo lo que necesita para su tarea del día.

1 — Los tres roles

Administrador
  • Acceso a todo el sistema
  • Liquida el mes (Cargos)
  • Maneja Configuración y Egresos
  • Ve el Dashboard completo
Profesor
  • Alumnos, Asistencia y Pagos
  • Registra su propia entrada/salida
  • Sin Dashboard, Configuración ni Egresos
  • Puede corregir un monto de deuda, como excepción
  • Puede marcar a un alumno como Activo/Inactivo a mano
Kiosco
  • Solo registrar asistencia (por DNI o nombre)
  • Ve el estado de cuenta durante ese registro
  • Ningún otro módulo

3 — Cómo funcionan los accesos (logins)

Un login por rol, no uno por persona

Hoy el sistema usa tres logins compartidos: uno para Administrador, uno para Profesor y uno para Kiosco. Si tenés varios profesores, todos entran con el mismo usuario de Profesor — no hace falta crear un acceso por cada persona.

Dar de alta a un profesor nuevo como persona (para que aparezca en la lista de Asistencia Profesores, por ejemplo) es distinto a crear un login: eso se hace desde Configuración → Profesores, cargando su nombre y asociándolo al login de Profesor ya existente.

¿Por qué no hay una pantalla para crear logins nuevos? Es una decisión deliberada, por seguridad: crear un usuario nuevo requeriría un permiso muy alto sobre el sistema, y se prefirió no tener ese riesgo dando de alta usuarios desde la propia app. Si en el futuro hace falta un login por persona (por ejemplo, para saber exactamente quién hizo cada cosa), es una mejora que se evalúa aparte.
